# ⚽ Football Match Predictor (AI)

This project is a Machine Learning application that predicts the outcome of English Premier League football matches using the **Random Forest** algorithm.

## 🚀 About the Project
The model analyzes historical match data (Home Team, Away Team, Goals, etc.) to predict the result of a match between two teams. It provides the probabilities for:
* Home Win
* Draw
* Away Win

## 🛠 Tech Stack
* **Python**: Core programming language.
* **Pandas**: Data manipulation and analysis.
* **Scikit-Learn**: Building and training the Random Forest model.
* **Matplotlib**: Visualizing the prediction probabilities with charts.

## 🎯 How It Works
1. The model is trained using the provided dataset.
2. The user inputs the **Home Team Code** and **Away Team Code**.
3. The system predicts the outcome probabilities based on learned patterns.
4. A pie chart is generated to visualize the winning chances.
